## 📖 Sobre

A **Brototec** é um projeto fictício criado exclusivamente para fins de estudo e demonstração técnica.

O projeto simula o site institucional de uma empresa de tecnologia, permitindo demonstrar conhecimentos em desenvolvimento Front-end moderno, componentização, responsividade, acessibilidade e experiência do usuário.

> **Importante:** A Brototec **não é uma empresa real**, não oferece serviços e não possui clientes. Todo o conteúdo foi desenvolvido apenas para compor meu portfólio profissional.

## 🚀 Executando o projeto

Clone o repositório:

```bash
git clone https://github.com/SEU_USUARIO/brototec.git
```

Entre na pasta:

```bash
cd brototec
```

Instale as dependências:

```bash
npm install
```

Execute o ambiente de desenvolvimento:

```bash
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```

Visualizar a build:

```bash
npm run preview
```
